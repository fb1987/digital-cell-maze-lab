## Score and selector contrast

Use paired ordinary emitted masks for the same layout/source and two goals.
Let P0/P1 be evaluator-only shortest-path vertex sets. Remove shared vertices and
BOTH goal-marker vertices to define exclusive interior arms A and B. If either is
empty, the pair receives no branch proxy (adjacent and two-edge shared-prefix
choices remain assessed by exact pair completion). If either response does not
normally emit, its paired proxy is zero. Do not force extra ticks or retune stops.

Let X/Y be the two output sets. Define d0 = fraction of A in X minus fraction of A
in Y; d1 = fraction of B in Y minus fraction of B in X. Contrast = max(0,(d0+d1)/2).
Multiply by the weaker output's full-raster path F1, where F1 = 2|output∩path| /
(|output|+|path|). This includes all extra output in its denominator. Proxy lies in
[0,1]. Identical floods, constant branch masks and marker-only switching get zero;
correct paths get one where interior arms exist. One-sided progress may get partial
credit, but the gate separately requires d0>0 AND d1>0 on at least one normal pair.
Oracle paths/labels NEVER enter candidate inference. Score is specific to these
unique-path tree fixtures; no claim about a choice among equal shortest routes.

Current rank reproduces M: complete pairs, individual shortest, individual legal,
correct minus false no-path, old partial + twice weaker paired partial. Choice
inserts summed branch proxy immediately AFTER complete pairs and BEFORE individual
counts/corridors. Same digest/identity tie break. Both lexicase routines process
shuffled cases with fields pair-correct, branch-proxy, shortest/no-path, legal/no-path,
old partial plus weaker partial. Current sets the proxy field to zero. Epsilon .02
only on the proxy and old partial fields. Same RNG and 64 simulated parent draws.
Top quarter elites with identical protected anchors; top two unprotected-by-rule
nominees, allowing the nominees to reveal the objective rather than force anchors.
No new generation is created. Independent validation selects one of each policy's
two nominees. Push all choices BEFORE independent final generation.

## Gates fixed before candidate calls

Software gate: graph/corpus checks, synthetic proxy ordering, unchanged current
selector parity, exact one-edit/RNG replay, same production runtime, and timing
projections pass. Unit tests use saved fixtures only.

Calibration gate, separately per group/topology:
1. Current versus choice changes at least 16/64 parent identities, elite membership
   and nominee sets (set changes, not order alone).
2. Mean branch proxy among choice parent draws exceeds current draws by at least
   .01 on proxy-eligible paired inputs.
3. At least one choice nominee has mean proxy≥.02, ≥4 positive paired poses across
   ≥2 seeded templates, at least one three-edge positive pair, and at least one
   strict-both interior response (d0>0 and d1>0).
4. A sampled child has a ≥.10 paired proxy increase over its own parent on an
   eligible pair, with strict-both interior response on that pair. This is a
   mutation-opportunity diagnostic, not a claim of evolutionary improvement.
5. All protected anchors occupy both elite sets, with exact unchanged programs.

Validation/final still run to diagnose transfer even if calibration fails; no
pilot follows a failed gate. Final gate for the validated choice: mean proxy≥.02
and ≥.01 above current choice, ≥4 positive paired poses on ≥2 seeded templates,
≥1 three-edge positive and ≥1 strict-both response; complete pairs must not be
below current. Protected anchors are explicitly preserved and evaluated in both
policies, rather than claiming selected nominees retain their corridor skill.

A pilot is eligible only if at least 2/3 groups within the SAME topology pass BOTH
calibration and final gates. Never pool one local and one evolved-range group.
If eligible, separately freeze a roughly 12-minute matched current/choice pilot
using identical 96-organism initial pools/RNG and protected anchors, common archives,
mutation/curriculum, resampling/frozen controls and exposure held fixed. Preserve
all next populations/RNG. No pilot before calibration gate/transfer evidence.
A larger 60–90-minute run additionally needs normal held-out non-adjacent paired
improvement in ≥2/3 evolutionary replicates, protected-skill retention and a
visible pressure contrast. Proxy-only gains never suffice for that larger gate.
