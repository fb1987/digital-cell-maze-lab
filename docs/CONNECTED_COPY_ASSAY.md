# M18: initialized, connected duplication

## Question and authorization

The user authorized proceeding after M17's proposal to check donor initialization and attachment to an existing reader before a sustained evolution comparison. M18 is that bounded mechanical assay. It does not evolve populations, inject a solver, claim acquisition, or authorize a subsequent long run. All previous histories, seals and final panels remain closed.

Can a generic copy inherit its donor's stimulus initialization, serve an existing reader, and preserve useful behavior under unchanged execution bounds? We distinguish logical trajectory preservation from operational neutrality: extra work can exhaust an unchanged budget earlier even when every shared completed tick agrees.

## Runtime and invariants

M18 wraps the M17 ten-channel genome with ten source/goal initialization tags. The first eight tags are fixed at the old convention; unused spares initially have zero tags. Only copying may inherit a donor tag. No inference call accesses the evaluator, an oracle, case IDs, known paths or arbitrary code. All prior local primitives, synchronous updates and stopping rules remain unchanged.

Capacity remains 256 total instructions, 31 primitive nodes per block, 256 ticks, 4,096 reads per grid site and 32,768 dispatched instructions per site. Empty embeddings reproduce all saved reaction fields except memory, which increases by 8 bytes per site plus 162 metadata bytes relative to M1. This includes both spare state arrays, extended port/offset structures and ten initialization bytes. Report additional copied writer instructions and actual work explicitly. No speed claim follows from this assay; timings include cold compilation when encountered and are not warm comparative benchmarks.

For an exactly initialized pure copy, induction predicts equality of the copied and donor state and of the first eight original channels at every shared completed tick, including self-reader cases. This does not predict equal stopping under a finite work cap. The software tests include a deliberately tight dispatch budget where the original completes one tick and the connected copy completes none. We do not raise production caps to hide that effect.

## Registered endpoints

Report every copy and intervention; no post-final role substitution or winner selection.

1. **Functional trajectory preservation:** for initialized pure copies, first-eight-channel equality with the exact anchor at every shared completed tick and copy/donor equality at every recorded state. Any violation stops the workflow for diagnosis.
2. **Bounded response neutrality:** exact equality of final masks, statuses and completed steps with the anchor on all 1,680 final inputs. Also report each field separately, all differing case IDs, correct response gains/losses, work and memory. This criterion is stricter than retaining all correct responses; neither substitutes for the other.
3. **Demonstrated reader coupling:** compare a copied-writer-zero intervention with its matched pure copy. A difference in original-channel state at a shared completed tick establishes propagation from that intervention in that finite trace. Different stop times alone do not establish it. Report disconnected controls, the number of eligible variants showing effects, and effects on final responses separately.
4. **Initialization contrast:** compare prespecified seeded/zero conditions for each identical anchor/edge/target. Initialization can be irrelevant for donors that were initially zero; report that denominator rather than treating all pairs as independent seed tests.

Retain ordinary length strata, exact-root/parent/protected-union comparisons, old strict skill-gate calculations and correct/false disconnection counts as descriptive context. Designed zero interventions or routing gains in a mechanical panel are not evolved discoveries or proof of evolutionary accessibility. All aliases are correlated; this assay has two related anchors and no independent-replicate or statistical significance claim.
