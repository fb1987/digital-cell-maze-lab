# M17: generic duplication into spare state

The user authorized this bounded experiment with “Procrrd” after M16's proposal.
M16 and all earlier histories remain sealed. No continuing evolution, recombination,
solver injection or cloud compute is part of M17.

## Hypothesis and representation

Can generic copying into unused state make combined upstream routing and retained
skills more accessible than the unchanged M1 neighborhood or copying over an
existing writer? M16 identified interference but did not prove eight channels
insufficient. This is a bounded accessibility test, not an expressivity proof.

M17 has ten uint16 state channels, with the first eight identical to M1. Channels
8/9 start zero and their writer blocks are empty/inactive. Each block retains eight
readable channel ports and the exact M1 scratch registers, flags and primitives.
Its ten-entry input permutation exposes only the first eight entries; swapping a
latent entry into those eight can expose spare state. Original input permutations
are extended with 8,9. No new arithmetic, connectivity, routing or halt primitive.

Neutral embedding has identical legacy state by induction: the first eight blocks
read only original channels; inactive extra writers leave zero; extra channels
cannot change the quiet check. Instruction/read counts, outputs, steps and status
are identical. The substrate allocation increases by 8 bytes/site plus 152 bytes
of offsets/port arrays. Test this on artificial/random genomes, intact controls,
normal/tight limits, and every scientific anchor/protected embedding on identical
inputs. Keep memory as a measured difference, not an equality field.

Activated extra blocks execute after original blocks, use synchronous old state,
and participate in quiescence. Copying may change stopping or exhaust the same
work budget earlier even without new downstream reads. This is part of its cost;
neutrality applies to empty embedding, not arbitrary activated copies.
All arms retain 256 total instructions INCLUDING active output writes, 31 nodes
per block, 256 ticks, 4096 reads/site and 32768 dispatches/site. Spare memory is
bounded by 42*sites + program/ports/offsets/register arrays. Blank blocks emit no
write. Generic mutations can activate an empty block with one random node.

## Fixed paired pool

Use exact M15 child g320/b48 and its actual genetic parent gated_specialist,
M16's preserved source packet, and all twelve protected references. Preserve
random-origin ancestry. No M16 confirmation-driven choice of a new anchor.

For each anchor generate 512 paired draws, alternating total depths 3 and 5.
Each draw records a random original-channel donor, a distinct random original
recipient, a random spare slot 8/9, and separate initial/later RNG seeds.
Three arms receive one initial variation opportunity followed by 2 or 4 generic
mutations:

- unchanged: an ordinary unmodified M1 mutation, then unmodified M1 mutations;
- overwrite: generic donor copying/rebinding into the original recipient, then M1;
- spare: the same donor copied/rebound into the spare slot, then generalized M17.

Copying exchanges donor/recipient roles only in the copied block's ports; all
other writers remain intact in the spare arm. Caps yield recorded no-ops.
The generalized operator uses ten module targets and ten permutation positions,
otherwise M1 operations; selecting an empty writer activates one random primitive.
No operator knows the maze, successful channels, or desired answer. Generic copy
is prospectively enriched in both copy arms; it is not a naturally sampled rate.
Same later seed per paired draw, but divergent genomes/domains may consume RNG
differently; save/replay full event and RNG histories. These are related fixed
neighborhoods, not independent evolutionary populations.

Each arm gets 1,024 proposals and 4,096 total variation opportunities. Add 256
common random M1 bodies and their 256 neutral embeddings. Exact anchors/protected
and intact flat/M1 controls, plus neutral embeddings of modular references, are
separate controls. No seeded solver enters candidate ancestry. All models frozen
and committed/pushed before fresh screening. Physical deduplication preserves
logical aliases and is reported per arm. Same nominal evaluations are not equal CPU.
This three-arm design measures a package of extra state plus changed accessibility;
it does not isolate the causal contribution of every operator change.
