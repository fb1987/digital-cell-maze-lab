# M1: generic modular random-origin discovery pilot

October 20, 2026. This is explicitly informed by completed C1 confirmation:
real, narrow acquisition in related deep-campaign lineages, no broad transfer.
No completed study is resumed, edited or relabelled. Random-origin discovery
remains open regardless of this bounded pilot's outcome.

## Hypothesis and contrasts

Can a bounded representation with private expression blocks make useful local
mechanics easier to acquire and retain? Does broader ordinary-maze exposure help?
Test a 2×2×2 design: flat/M1 × familiar/broad × mutation/random-resampling, with
three independent fresh founder seeds per representation, 96 organisms/condition.
The exact same founder population is cloned across its four curriculum/method
conditions. Across representations, random distributions differ by construction.
Seeds and all inputs/source are frozen before scientific evaluation.

M1 has eight blocks, one fixed output writer for each of the eight persistent
uint16 channels. Each block has private single-assignment scratch nodes and eight
explicit permutable input-channel ports. References can address inputs or earlier
nodes. Up to31 nodes/block, total nodes plus eight output writes <=256. Initial
64–128 total instructions. Existing arithmetic, logic, local-neighbor and gating
primitives remain; STORE becomes one fixed output port. All communication reads
last tick's state. No distance wave, path extraction, pruning, BFS, oracle,
solver-specific phase or trained module is inserted in any founder or offspring.
Initial source/goal pulses, endpoint flags, output channel2 and halt channel7
retain existing hardware conventions. These are disclosed inherited conventions.

Seven mutation opportunities: replace, insert, delete, duplicate node, input-port
swap, within-genome block copy with generic channel-role rebinding, or operand/
gate change. Bounded fallback/no-op possible. This is not sexual recombination.
Flat genomes use the existing rich64–128 founder distribution, 256 cap and old
one-edit operator. Consequently the representation AND variation package is the
factor; a result cannot isolate private registers or attribute it solely to
modularity. Both use 256 ticks,4096 reads/site,32768 dispatches/site, local-only
sensing,8 state channels. M1 output writes are charged. Actual cost includes
interpreter overhead; equal evaluation allocations do not imply equal compute.

The handwritten intact solver is separately compiled into M1 as an engineering
expressivity control. It and the old intact VM are never reproductive ancestors.
The compiler is also used for software checks of random M1 semantics against the
old native interpreter. Extra scratch clears mean converter work is unequal;
this is a semantic test, not a speed comparison or scientific inference repair.

## Search, retention and nomination

128 fixed rounds; 10 local workers; all24 conditions complete the same rounds.
Each round evaluates96 organism slots on24 queries,16 reachable and8 disconnected.
Paired conditions use identical batches. Familiar:18 structured+6 ordinary;
broad:6 structured+18 ordinary. The shared structured block and first two ordinary
bases/family overlap. Structured prefixes0/1/2/4/8 and poses rotate; fork, second
junction and real cycle schedules are fixed in source. Ordinary train families:
Wilson perfect11, random9, partition-disconnected9. No oracle difficulty filter.
This is a fixed broader mixture, not adaptive adversarial training.

Common selection:16 aggregate-merit survivors, then new exact-success coverage,
then epsilon-lexicase without replacement to44. Case values prioritize correct
shortest/no-path, valid/no-path, avoiding false no-path, then existing bidirectional
partial fitness with branch/stray penalties (epsilon .02). Aggregate rank equally
weights represented families: correct-minus-false-no-path rates, valid-minus-
false-no-path rates, partial progress. This common selector differs from the old
campaign; this study cannot attribute any cross-study improvement to representation.
Mutation arms have7 random immigrants+45 one-opportunity children; resampling has
52 random births. Parent choice uses the common survivor pool and lexicase.
Every selected parent, edit, child, RNG state and receipt is preserved/replayed.

One fixed200-query development panel: four old-grammar structured contexts,
paired poses0/4, corridors pose0, prefix0 disconnected pose0;12 ordinary bases
per train family, poses0/4. All live members are assessed at0,32,64,96,128;
a16-member external coverage archive and two frozen initial nominees also have
assessment slots thereafter. Archive candidates do not breed unless also live.
Each condition receives equal nominal evaluation slots:96 at initial assessment,
114 at later assessments; exact duplicate identities/models are physically reused.
Report physical and nominal counts separately. No post-cap nomination.

Nominate two: best aggregate rank and best ordinary-reachable rank among live,
archive and frozen references. Deterministic identity tie-breaks. No downstream
selection on final cases. Exact genomes/roots/immediate parents, ancestry and all
final states are frozen and committed/pushed before confirmation generation.

## Untouched confirmation and decision screens

Final seed2026102012 uses the registered C1 generator on wholly new layouts:
12 structured contexts (old grammar, not novel-topology transfer),400 paired
opportunities,200 corridors,40 structured disconnected, plus32 bases×2poses for
perfect11/perfect15/random9/random15/disconnected9/disconnected15:1,424 inputs.
Size15 is outside this pilot's training and nomination. All eight poses excluded
even when unqueried. All historical C1/setup/rehearsal layouts are excluded.

Assess all nominees, their matching frozen initial nominees, exact roots and
immediate parents, plus separate intact flat/M1 controls. BFS/A*/bitwave on the
same inputs independently establish baseline correctness; no latency claim.
Report every condition and rank, paired gains AND losses, corridor retention,
ordinary base success in both poses by family/size, correct and false no-path,
mutation depth/root identity, and descendant-versus-parent comparisons.

Routing acquisition: mutated descendant gains>=8 complete pairs across>=2
contexts, retains>=90% of root paired/corridor successes, with no increase in
false no-path. Empty retention denominators are N/A. Broad acquisition additionally
requires>=4 new ordinary bases correct in both poses, including perfect and
random, and>=90% ordinary-root retention. An immigrant with no mutation depth
cannot be credited with evolved acquisition.

A representation/curriculum combination passes the long-run screening criterion
only if at least2/3 mutation replicates have either preselected nominee passing
broad acquisition, net>=4 ordinary-base gains over its matching frozen nominee,
>=4 more ordinary bases than its matching resampling nominee, and no greater
false-no-path count than resampling. All results are descriptive with only three
replicates; shared test panels correlate observations. Failure is not proof of
impossibility. No automated long campaign or architecture retuning follows.
Compare representation contrasts within common curricula and curriculum contrasts
within common representations; do not claim private-memory causality.
