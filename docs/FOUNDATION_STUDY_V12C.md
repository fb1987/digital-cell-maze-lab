# V12C: a stable 75-minute random-origin elementary-skill experiment

This protocol is fixed before main training. V12A's negative repair calibration and V12B's passing confirmation remain separate. V12B selected one requested edit per offspring from validation, then passed fresh confirmation (3/3 west-return,2/3 output-register,1/3 two-return repairs). That supports a searchability check, not a claim that repair predicts discovery or that single edits are universally better. No intact or repaired control enters a random-origin population.

## Question and controls

Can an unchanged, bounded search acquire transferable short goal-dependent routes and retain earlier skills when given substantially more stable evolutionary time? Test native V11 cap256 populations and separately labelled fresh random populations, each under local/evolved-range topology, evolution/resampling, and three replicates:24 conditions of96 organisms. Initial validation selections are frozen controls. The primary comparison is evolution versus resampling within each origin/topology/replicate. Fresh versus native and topology comparisons are also reported; native topologies have different historical ancestry and are not a clean topology intervention.

Native founders are the full96 prepared organisms in each `results/capacity_growth/checkpoints/growth_{local|evolved}_cap256_{0|1|2}.json`, including their original RNG states and founder references. Every earlier population/protected variant remains on disk. Fresh founders use the unchanged rich64–128-gene random factory, seed2026101815, matching across topologies. Evolution/resampling pairs have identical initial genomes and RNG; their later RNG draws diverge with the operators. The profile descendants are discarded. Resampling retains the same12 elite/niche slots but independently redraws the other84; it is repeated random sampling with selection, not evolution through mutation. Evolution retains12, draws9 random immigrants and produces75 one-edit children. Parent selection is existing epsilon lexicase with10% uniformly random parent choices. There is no unbounded active archive; per-level validation archives are saved but not injected into reproduction.

## Stable learning conditions

Use unchanged V11/V6 candidate semantics:8 state channels, at most256 genes, goal pulse enabled, local/evolved-range controls, and ordinary stopping. Training/validation limits are256 ticks,4096 reads/site,32768 dispatches/site,65536 cells hard ceiling. One edit can replace an instruction or duplicate up to8 genes, not necessarily flip one bit. All mutations are logged and replayable. Fitness is V12A's ordinary-output score: legal complete paths, shortest paths, explicit no-path utility, complete shortest goal pairs, then bidirectional thin partial-path credit. Work only breaks ties when all outputs are complete. No forced development, BFS or graph oracle is allowed inside candidate inference.

Each generation has exactly12 normal inputs per organism:four rotations of one fresh current-level goal pair, one recall pair and one preview pair. Reflection alternates. Tree/cyclic family alternates. Recall cycles among earlier levels (another level0 group while at level0); preview is one level ahead, capped at3. Every eighth generation replaces preview with a mixed reachable/disconnected goal pair. All24 conditions see the same tasks within each replicate, and all receive identical response counts and validation slots.

Four levels use source-goal distances1,2–4,4–8,8–16, with progressively longer common prefixes and disjoint shortest-path exits. Levels0–2 use9×9 mazes and level3 uses17×17. Endpoints vary. D4 symmetries transform the original fork anchor as well as the layout, avoiding changes caused by BFS tie order. Validation:two independent base layouts per level (tree/cyclic) plus one mixed reachability layout, all eight symmetries and both goals:144 responses,136 reachable. Initialize by evaluating every founder; every eighth generation validate exactly four nominees, even if genotypes coincide.

Curriculum is shared across all eight conditions within each replicate. It starts at0. After at least20 generations at a level, it advances only if a single validation-tested candidate from any condition achieved≥90% complete shortest pairs at the current level and≥80% at every earlier level. Certificates identify that candidate and its rates. Separate specialists cannot collectively pass retention. This shared exposure favors comparability; it may move a weaker population ahead of its own competence, which is reported. Validation competence and per-level archive accuracy are secondary; they never replace fresh exact-route measures.

## Time, memory and reproducibility

One fixed **4,500-second (75-minute)** local search budget, including initialization, case construction, ordinary evaluations, selection and checkpoint I/O; initial JIT warmup is separate. Finish the current complete matched round when time expires. Hard generation cap4096, compressed/output disk bound4GiB and process RSS bound8GiB, checked at10-round checkpoints. Resource-bound termination is reported and never called a completed75-minute test. No performance-dependent extension or early stop. Profile on already excluded V12A fixtures took75.99s for eight founder screens plus three generations each; generation throughput suggests hundreds of rounds, but actual rounds and per-condition work are measured rather than promised.

Save full next populations/RNG, all founder/mutation traces, raw normal rasters/scores/counters, validation archives and curriculum certificates. Atomic global checkpoints every10 matched rounds contain all states, ordered data keys and committed log segments. On resumption rebuild deterministic data in its original order, verify source/input hashes, and retain incomplete segments as explicitly uncounted orphan files. Resume overhead consumes remaining budget. Compare exact uninterrupted versus checkpoint-restored states in tests. Round order rotates without consuming candidate RNG. Every selected model is frozen and hashed before final layouts are generated. Code, seed, environment and prior revision hashes are recorded.

Exclude **17,748** previously constructed whole layouts:17,700 throughV12B plus48 in the schedule unit fixtures. Profile inference otherwise uses only already excluded V12A fixtures. Reject any new orbit that overlaps any previous layout, regardless of endpoints. Train/validation/final layouts are separate, including rotations/reflections. Pose/goal repetitions and duplicated genotypes are correlated observations, not independent discoveries.

## Fresh confirmation and interpretation

Generate final layouts only after freezing. Elementary confirmation:three independent base layouts per level/family/replicate, allD4 poses/two goals:24 base groups and384 responses per replicate. Evaluate every primary global champion and initial frozen control on all levels. Evaluate each per-level champion and its initial counterpart on that level as explicitly secondary results. Record complete shortest pairs, individual legal/shortest outputs, shortest distance, family, orientation, budgets and failures. Report replicate results, base-group rates and matched controls; no claim from a proxy-score gain alone. A useful elementary signal requires evolution to beat both resampling and frozen selection at distances≥2 in at least two replicates, with completed shortest pairs in at least two fresh base layouts per passing replicate. This is a screening criterion, not statistical proof; report all counts and no post-test tuning.

Ordinary generalization:per replicate8 tree and8 cyclic cases at each of9,17,33,65;4 disconnected cases at each size;4 rectangular cases at each of9,17:88 cases,72 reachable and16 disconnected (264 total). Use1024 ticks,8192 reads/site,131072 dispatches/site for this distinct final stress budget; report it separately from training/microconfirmation. Whole orbits are excluded and saved; only declared primary orientation is queried for this ordinary corpus. BFS, A* and bit-wavefront emit full reference rasters. The seeded wavefront remains a separate feasibility reference, with any budget failures reported. Snake/comb templates are omitted because their repeated layouts cannot be called unseen.

Timing includes bytes-to-array decoding, state initialization, updates and emitted raster. Warm the exact production dtype/mutability/signature. Thirty warm randomized repetitions for references on the first17/33 tree/cyclic case per replicate; include candidate models only where they actually return a valid shortest route on that case. Also time each model's first valid non-adjacent elementary case if one exists, against the same references. Report medians/ranges and array payload estimates separately from process RSS. Invalid routes receive no speedup credit. A tiny-task win would not establish superiority over the best general-purpose solvers.

Audit all source/input/selection hashes, layout exclusion and transformed labels; all mutation ancestry; response/work accounting; every validation/final raster and every training record claiming a valid route, plus a deterministic1/512 sample of other training records. Independently grade saved masks/scores; replay every distinct final candidate/case result and reference raster. Use bounded streaming ancestry storage. Record audit/replay cost separately. Training/validation archive claims must agree with the saved records. Full suite already128 passes before V12; focused tests cover current additions and exact resume. Final new code gets appropriate regression checks; historical raw/source files stay immutable.

Post-hoc frozen-model interventions may test goal pulse/nonlocal use on successful cases; clearly distinguish them from new independent confirmation. Raw hidden-state contrast, genome length or adjacency-only outputs cannot establish a general maze-solving algorithm. Freeze and report all negative results. End with one justified next decision, rather than automatically adding another fitness term or extending time.
