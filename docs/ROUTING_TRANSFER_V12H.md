## Matched graph construction

Study seed **2026101903**; separate construction/calibration seed **1224**. No

There are **48 independently sampled base contexts**, 24 in each route band
5–9 and 10–18 edges. Both goals fall within their band's limits. Every context
uses a 25×25 board, an interior source, a shared incoming path and distinct goal
arms. Construct three matched graphs with the same two unique shortest paths:

1. An induced three-arm fork.
2. The same fork plus one dead-end branch at an internal shared-prefix vertex:
   exactly two degree-three junctions in the source component.
3. The fork plus an induced alternate path between two internal prefix vertices:
   exactly one cycle, three degree-three junctions, and exactly two simple paths
   to each goal. The alternative is 2–12 edges longer and its raster is itself a
   legal non-shortest path. This is not a dangling loop.

The dead-end arm is a truncated part of that alternate route. Added vertices
cannot touch the original graph elsewhere. Eight isolated clutter cells are
shared across all variants and controls. They diversify layouts but need not be
computationally neutral. The grammar remains narrow, and local shapes may recur.

## Decision rule

A fixed model passes the restricted robust-transfer screen only if, in the
10–18-edge band, it completes pairs on **at least6/24 independent contexts in
each of the two-junction and alternate-cycle families**, including **at least2
all-eight-pose contexts in each**, and retains at least12/24 any-pose long forks.
Report this for every primary and frozen/resampling model. Stronger follow-on
selection/evolution work requires at least **two of three Branch replicates in
one origin/range cohort** passing this screen. A single passing lineage remains
valuable mechanistic evidence but does not meet that replication criterion.

Passing does not authorize an automatic hour-long run or imply general solving,
an evolutionary advantage over resampling, multirange necessity, or a speedup.
If the screen fails, use the matched failure and mechanism evidence to specify a
bounded next hypothesis. Fresh random-origin discovery stays active regardless.
