## The single changed objective

Current uses the existing hard ordering: complete pairs, shortest outputs, legal
outputs, correct-minus-false no-path, then aggregate partial score. Per-case
lexicase similarly prioritizes exact pair/shortest/legal outcomes before partial
fitness. The current partial score already penalizes branch junctions.

Selective replaces ONLY the partial-score value supplied to that same evaluator
and lexicase. Let L be the unique oracle route length in cells, TP the number of
illuminated oracle cells, and E the illuminated off-route cells:

- Exact normally emitted shortest output:1.
- Unreachable case or non-emitted result:0.
- Complete route present but extras remain:0.5+0.49/(1+E).
- Incomplete route:0.49×(TP/L)^2/(1+E).

Empty output gets0. A flood remains invalid and below every correct solution;
it is intentionally ranked above incomplete routes in the shaping tier to avoid
removing needed path cells simply to gain precision. More excess always lowers
its score. The paired weak-case minimum is combined exactly as in current
fitness. Raw masks/statuses and original partial fitness are preserved; a new
selectivity field records the observer score for ALL arms. No oracle information
enters inference and no emitted raster is cleaned up. No causal success follows
from the synthetic ranking alone.

Synthetic fixtures explicitly check exact/empty/partial/flooded masks and
one-/two-/four-cell branch stubs on the SAME maze. Current ties those three stubs;
selective strictly orders them. Independent set-based scoring and raster grading
must agree. Separate known intact/damaged controls enumerate64single-operand
repairs of the output STORE, verifying that both objectives can select an exact
repair on40prefix1/2 inputs. These constructed controls never enter populations.

least8prefix1/2 pairs relative to its frozen reference, including at least4new
prefix2pairs, across at least2new contexts and2poses. Upstream total must exceed
resampling and frozen by at least8; selective must also exceed current by8.
Retain at least95% of the frozen reference's ACTUAL successful pair and corridor

is not evidence for selective pressure. Failure closes this pilot without extension.
The gate motivates a future registration, never automatic long-run execution.
