# M29: state interference, insulation and coupling feasibility

User authorized “Proceed” after M28's recommendation. This is a bounded mechanism
study on **previously used development cases**, not evolution or independent
confirmation. No new maze, solver, breeding genome or selection campaign is made.
All old sealed files, journals, populations and RNG histories remain unchanged.

## Questions and fixed material

M28 could not combine opposite-pose specialists by exchanging writers or fusing
one local expression. Test whether their **state trajectories** differ in a way
that changes an imported expression, and whether explicit insulation can preserve
both inherited processes at a measured cost. Static dependence is not causal proof.

Use all 15 parental genotypes from ALL 38 complementary pairs, plus the fixed M28
INTEGRATED regulated nominee and its exact recipient/donor. All are random-origin
descendants. No favorable pair or edge is chosen using M29 results.

The 69-case fixed manifest uses:

- All four M27 complementary bases, poses 0/4 (8 inputs).
- All 28 M28 focal donor-corridor losses.
- All 12 new focal fork responses and all 12 failed alternative-side partners.
- The first queried disconnection case per family/size (3 inputs).
- The first queried ordinary 16+ base per family, both poses (4 inputs).
- The old 16-edge rare-win witness, both poses (2 inputs).

All are already used. Source-phase namespaces distinguish identical case IDs that
refer to different old layouts. Selection must use `queries.all`, never unqueried
or rejected metadata. Corpus, source objects, static graph, interventions and job
order are frozen and pushed before scientific execution. No new heldout cases.

## Four diagnostic phases

**Native/passive traces.** All 15 parents on the 8 complementary inputs; focal
recipient, donor and regulated child on all 69 cases: 311 native runs and 311
passive traces. Existing M18 inference is unchanged. Each passive result must
match every native response field/work count and the independent raster grader;
all available old source rows must reproduce. Save all completed-tick channel
states, preserving normal stopping and budgets. No forced continuation.

**Static and insulated embedding.** Build both output-cone and full-execution
dependencies. A conservative structural sharing rule starts with byte-identical
writers/ports/initialization, then removes channels whose dependencies cannot be
shared. Report `20 - shareable_channels` as a sufficient copy width, **not a
semantic minimum or proof a smaller representation is impossible**. Global quiet
and budget behavior require independent accounting even for common expressions.

A diagnostic 20-channel, two-bank interpreter embeds both unchanged ten-channel
programs. Total inherited instructions must still fit 256; per-writer limit stays
31 nodes. Each bank has its own original 256 ticks, 4096 reads/site, 32768
dispatches/site, quiet counter and stopping latch. Both banks read the same
pre-tick snapshot; a stopped bank freezes. This can use **twice the original total
work allowance**, and has larger state and latch metadata. Charge all actual
reads/dispatches and report array/trace allocation, CPU and wall separately.

Run all 38 pairs on all 8 target inputs plus the focal pair on the other 61 cases:
365 paired executions. Require exact parent histories at every recorded tick,
exact terminal fields/work, and frozen states after each parent's own stop.
The fixture returns TWO internal rasters and has NO output selector. It is a
feasibility diagnostic, **not a combined organism, maze solver or free ensemble**.
No enlarged diagnostic runtime enters evolution.

**Prospective coupling.** On the focal pair enumerate ALL 37 live output/halt-cone
reader-port positions across both parents. Redirect one existing input port to
the other bank's homologous channel, preserving generic local primitives. No
favorable edge subset, retries, or M29-based choices. Test each on the same eight
targets: 296 executions. Count receiver history and terminal-field changes and
edges preserving both processes. The other bank has no return edge and MUST stay
exact. These interventions still expose two internal rasters; report neither a
selected winning raster nor a new solving claim.

**Writer-context interventions.** For each focal case, compare the recipient's
and donor's original C6 expression evaluated on their own saved state versus the
regulated child's saved state. Verify its own next C6 value on EVERY common
completed tick. Find the first tick whose imported-expression result differs.
Then replace each single channel of that shared state with the corresponding
parent state and test exact one-step restoration. Also restore the entire static
execution-input channel group and the full parent state as positive controls.

These saved-parent-state interventions are **diagnostics**, never candidate input,
fitness, output switching, breeding material or oracle-derived path answers.
An exact one-step rescue supports a causal local input effect; it is NOT a rescue
of the full trajectory or maze solution. A negative result only concerns the
recorded common window, writer and cases.

## Verification, bounds and closure

100000 kernel/full-grid-writer executions and 1e12 counted work per phase,
8 GiB sampled process-tree RSS, 2 GiB TOTAL phase storage including preparation,
failures, logs and backups, 16 GiB disk free floor. Elapsed is max(monotonic,
calendar) so sleep counts. No second writer, bounds extension, cloud compute,
automatic failed resume or silent repair of frozen science.

Native+passive is two executions; each dual-bank call is one diagnostic kernel
executing both banks; each full-grid expression invocation is one writer execution.
Report these categories separately rather than treating unlike executions as
equal-cost candidate evaluations. Reserve conservative maximum work/calls before
dispatch, fsync receipts and commit result/history bytes to a new SQLite journal.
Failure preserves traceback, pending reservations, receipts and original outputs.

Eight focused tests validate native equivalence including tight caps, stopping
latches, private/port semantics, delayed cross-bank reads, one-way interventions,
dependency closure and first-divergence reporting. Discarded preflight exercises
all four phases on artificial constant/copy programs and already excluded cases,
including a nonvacuous channel restoration. Pre-registration test harness errors
and a query-filter preparation failure are preserved; no old science is repaired.
