# V13A: stopping versus persistent branch overgrowth

This is a Z-informed fixed-panel mechanism test. It is not another evolutionary
run, a new selection contest, or a sexual activation pilot. No candidate is
edited, no saved population/RNG is resumed, and no known solver enters a lineage.
The separate intact solver is a positive control. Freeze and push panel, source,
fixtures and timing decision BEFORE generating scientific cases.

## Inference, interventions and trace endpoints

Run normal native inference for EVERY panel member on ALL cases first. On all
13 named target aliases (nine Z primaries plus four controls), independently run
pulse-off, flag-off, both-off, endpoint-check-off and halt-request-off.
Interventions use paired AND corridor inputs at prefixes0/1/4, all contexts/poses.
Native quiescence and work caps remain. Endpoint-off and halt-off are different
interventions. None is a promoted solver; record new successes and loss of genuine
normal successes separately. Correct paths and shortest paths remain distinct.

Then record96-tick forced trajectories for normal/pulse-off/flag-off/both-off on
paired inputs in contexts0,1,4, prefixes0/1/4 and poses0,4. This subset is fixed by
metadata, never by success. Each forced run retains native read/dispatch caps.
Goal-pair both-off states must be identical. Forced raster/status is not an
inference result. Frame geometry is graded with an independent observer; oracle
information never enters a candidate. All states and masks are retained.

Primary diagnostic: among normally failed tasks/pairs, does shortest geometry
occur AFTER their native stopping ticks? Report actual recorded horizons,
simultaneous paired geometry, extra/missing cells and repeated FULL states, by
model/mode and prefix. Compare unforced halt-off outcomes separately. No best-tick
oracle stopping rule, repaired raster, or forced frame may count as normal success.
Repeated states concern bounded deterministic local trajectories; no claim about
arbitrary models or larger horizons follows. Success-conditioned losses establish
necessity only on those successful cases, not universally. Root/parent comparisons
are selected-lineage evidence, not causal capacity or replicated policy tests.
