# M3: retained-skill continuation with neutral variants and compound mutation

Authorized October21,2026 after completed M2. New phase, not an extension of M2
or a restart of the closed M1/deep campaign. All prior histories remain intact.
M2 found one two-opportunity gain but its formal breadth flag was satisfied by
mostly one-edge ordinary paths. M3 explicitly separates route complexity.

## Population and comparison

Six populations of96: three matched replicates × single/mixed mutation. Each
pair starts from identical96 exact preserved M2 genotypes. Six protected copies
per population: the two M1 wave anchors and M2 selective nominees a0/d1,a0/d2,
a1/d1,a1/d2. Ninety other distinct genotypes are seeded random samples from M2
mutants that changed genotype and retained every anchor-correct screening query
without new false no-path. This is explicitly M2-informed selection, not fresh
independent evidence. The three replicates share source lineages and protected
anchors; independent subsequent RNG histories do not make their origins independent.
New M3 RNG seeds, exact founders/source identities and prior ancestry are saved.
Within-M3 roots refer to these forked founders; older ancestry remains separately
preserved. No known solver or synthetic solver circuit enters reproduction.

Both arms use identical selection, archives, tasks and nominal evaluations.
Survivors44: six immutable protected identities, eight merit survivors, up to12
additional exact-success coverage survivors, up to18 genotype-distinct neutral
variants matching a merit representative's terminal raster/status on the current
batch, then epsilon-lexicase fills remaining slots. Neutral reserve is finite-
batch behavioral identity, not global semantic equivalence. Parent selection is
common epsilon-lexicase over those44. Births52: seven new random M1 immigrants
and45 mutated children. Single: one generic M1 opportunity each. Mixed:23 single
and22 consecutive two-opportunity children; intermediate not evaluated/selected.
All intermediate genomes/events saved. Same256 instruction/tick caps and M1 VM.

Common merit rank equally weights paired graph/prefix strata, ordinary family/
length strata, corridors and disconnected families. It orders correct-minus-
false-no-path rates, valid-minus-false rates, then existing branch-penalized partial
fitness. This changes M2's family aggregation prospectively, equally in botharms.
No objective or oracle is supplied inside inference; no raster cleanup. Protected
copies retain skills even when a mutable organism trades them away.16 external
coverage archive members and two frozen initial nominees per condition.

Hard-pair acquisition requires a mutated M3 descendant, >=8 new complete hard
pairs absent from BOTH its exact M3 root and the union of allsix protected references, >=2 contexts, >=90% root
paired/corridor/ordinary-base retention and no increase in false no-path. Empty

with distance>=8 absent from BOTH exact M3 root and protected union, both perfect and random, at leastone

BOTH plus>=4 new non-fork pairs. These labels are capability screens, not proof of
a general solver. M2's already-passed flag remains historically unchanged.

Exploratory mixed-variation screen: at least2/3 matched replicates have a prechosen
nominee passing either new acquisition gate and exceeding matching single-edit
nominee by>=8 new hard pairs OR>=4 new long bases, with no more false no-path.
Shared ancestral material and correlated mazes limit inference. No automatic
longer campaign, architectural change or recombination follows.

## Execution, preflight and audit

10 local CPU workers;12GiB process-tree RSS;12GiB phase storage recursively including
backups;16GiB disk free floor. Existing campaigns untouched. SQLite FULL/WAL,
single writer, durable receipts and conservative charged reservations. Unknown
or failed work remains charged. No cloud/model API. Final allowance separate:
<=1M calls,10^14 work,90min, same memory/storage guards. Audits additional replay
work, no search, logged separately; preserve any failed attempt and traceback.

Preflight uses discarded seeds/cases: controls on all392 queries, fullsix-condition
assessment plusfour generations, all1,248 births and population/RNG transitions
exact replay. Old genotype sources are used for representative timing only;
discarded descendants never become scientific founders. New unit tests cover
hard/length strata, root/identity and protection, neutral reservation, no-op/mixed
mutation counting, paired allocation and replay. A separate discarded final-generator fixture uses seed202610210105 and both
engineering controls on all1,680 inputs; every generated layout is excluded.
A synthetic report test validates complexity gates and canonical JSON equality
using already saved fixture responses, without any reproductive injection.
No calibration outcome changes
fitness, founders or success gates. Profile affects expectations only.

Search audit recreates every corpus and task, all selection/mutation/RNG/state
hashes; regrades every physical raster independently; native hash-fixed1/256 train
and1/32 assessment samples. Final audit replays ALL final native outputs, external
baselines and recomputed summaries using canonical JSON equality. Production VM/
mutation/selection are shared replay implementations, not a second full VM.
Preserve full journals, safe verified backups within bounds, and seal reports.

The sealed `tools/run_m3_workflow.py` runs durably in the background. It stops
on any exception or guard, publishes exact choices, runs the search audit, then
runs confirmation, analysis and full final replay in that order. Each subprocess
has a separate preserved log. It never resumes a failed workflow automatically.
A read-only monitor uses `tools/inspect_wave_continuation.py`, compares nominees,
frozen references and protected anchors on the identical development panel, and
notifies only on actionable change. Once both audits pass, the monitor reviews
the report, creates guarded SQLite backups, seals the completed evidence and
commits/pushes it. Confirmation here is specifically authorized by this M3 protocol;
the old deep-campaign monitor remains paused.
