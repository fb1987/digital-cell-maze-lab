## Measurements and common nomination rule

Primary solving outcomes are ordinary emitted legal/shortest routes and complete
non-adjacent goal pairs. N's positive interior-arm proxy remains unchanged and
explicitly diagnostic. Both goals/shared path vertices are excluded from arm
contrast. Also report signed contrast, marker-excluded goal response, strict-both
responses, corridor/no-path behavior, output/counter differences and real work.
Non-emitted rasters get no branch credit; no forced ticks or stopping retuning.
A negative response is detectable but wrong, not progress. Identical output does
not establish hidden-state equivalence.

A terminal is a *useful new response* relative to its own reference root if its
mean positive proxy over eligible pairs is≥.01, it has≥2 positive paired poses,
and≥2 eligible paired poses improve proxy by≥.10 over the root. This permits
partial one-sided progress for a MECHANISM EXPLORATION gate; it is NOT a solver
screen. Preserve all root skills separately and report losses in the terminal.
Random controls use their assigned unrelated reference slot by the same rule.

Common nominee rank, descending: non-adjacent complete pairs; useful-new-response
indicator; mean positive proxy; strict-both pairs; all complete pairs; correct
corridors; correct minus false no-path. Then program digest and identity. No work
tie-break. Use two nominees per arm, then one independent-validation choice. Save
all ranks, comparisons and identities. Nomination is retrospective to discovery
only, never to validation/final; there is no reproductive generation.
