# Pre-registration rejected geometry fixtures

Four contexts / 192 whole layouts / 320 inputs generated with fixture seed 1234.
No candidate inference occurred on these cases. Independent graph/raster checks
rejected the intended longer alternative: a cycle attachment one edge from the
choice vertex caused its illuminated raster to contain a shortcut chord.

Before calibration, attachments were restricted to at least two edges from the
choice vertex, with short tails changed from 2–4 to 3–4 edges. The corrected
fixtures use the same declared seed and reject every layout in this packet.
This packet is preserved and permanently added to the exclusion chain.
