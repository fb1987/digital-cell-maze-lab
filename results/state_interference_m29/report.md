# M29: what state insulation does—and what it does not explain

**Insulating the two parental processes preserves them exactly. However, the proposed wrong-context explanation was not detected at the transplanted C6 writer.** The regulated child changes which parental C6 values are emitted; these changes precede C2 differences in 38 recorded cases. No combined maze solver was produced.

All results below use previously observed development mazes. This is mechanism evidence, not independent confirmation or a new evolutionary search.

## Exact insulation feasibility

All 311 passive traces match the original M18 native response and work counters exactly. All 301 available original saved rows also reproduce. All completed-tick states are retained, with normal stopping and no forced continuation.

A separate diagnostic interpreter places the original programs in two insulated ten-channel banks. All 365 executions / 730 bank comparisons reproduce **every parent state at every completed tick, all terminal fields and all work counters**, with each bank frozen after its own stop. This includes all 38 pairs on the eight targets and the focal pair on the other 61 cases.

The fixture has **20 persistent channels, independent quiet/stop latches and independent original per-bank caps**. The sum of inherited instructions fits 256; primitives and the 31-node writer limit remain unchanged. Each bank still has 256 ticks, 4,096 reads per site and 32,768 dispatches per site. The total permitted work can therefore be twice the single-organism ceiling. It produces **two internal rasters and no selector**. It is not a combined solver, an evolved organism, or a free ensemble.

The modeled array footprint excluding trace is 1.955–1.977× the recipient's, median 1.973×. Work is exactly the sum of the two original executions: 1.126–8.888× the recipient's, median 2.002×. This ratio can exceed two because the other parent can take much more work than the recipient. Maximum modeled pair arrays: 36,991 bytes; maximum separate full trace allocation: 3,711,080 bytes. Python/wrapper temporaries are outside that array model; sampled process RSS is reported below.

A conservative structural sharing construction gives widths of 18 channels for 4 pairs, 19 for 22 pairs, and 20 for 12 pairs. It only shares byte-identical writers/ports/initialization with closed full-execution dependencies. This is a **sufficient direct-copy width**. It is not a semantic minimum, a proof that ten channels are insufficient, or evidence that evolution needs twenty. Common expressions and semantically irrelevant code could allow a better representation.

## The C6 shared-state hypothesis did not pass its intended test

| Contrast against the regulated child | Cases with some state divergence | Cases where the original C6 expression changes on the child’s state | Verified native next-C6 updates |
|---|---:|---:|---:|
| recipient | 48/69 | 0 | 1,575 |
| donor | 69/69 | 0 | 1,575 |

Across 3,150 native next-writer checks and 3,150 matched borrowed-context evaluations, neither original C6 expression changed its result on the fused organism’s state within the common recorded windows. Consequently no scientific channel-restoration intervention was triggered. The positive restoration branch is exercised nonvacuously in the discarded artificial preflight; zero triggered interventions in the real study is not a failed positive control.

This contradicts the specific expectation that the imported C6 expression would fail because its parent’s state context was missing in these cases. It does **not** rule out state interference at another writer, another stage, later unrecorded ticks, a different genotype, or through global stopping/budget costs.

## What the saved traces do show

The parents' C6 values differ on 66/69 cases. The regulated child uses recipient values at disagreeing sites/ticks on 66 cases and donor values on 48. Every recorded regulated C6 value equals one of the two native parent values in the common window. This agrees with M28's actual genotype: two expressions followed by a local SELECT, rather than a preserved second complete process.

Relative to the recipient, the child's first state difference is C6 in 48 cases; there is no state difference in the common window in the other 21. In 38 cases, a C2 difference appears after the C6 difference. These timings show propagation, but temporal order alone is not a causal proof of the entire maze failure.

The prospective coupling interventions provide a stronger local causal result. All 37 output/halt-cone port positions were tested, each on all eight target inputs. Only four positions change the receiver’s history; each changes the final raster on all eight inputs. All 296 uncoupled donor banks remain exact.

| Receiving bank | Receiver writer | Crossed physical input channel | History changes | Final raster changes |
|---|---:|---:|---:|---:|
| 0 | C2 | C2 | 8/8 | 8/8 |
| 0 | C2 | C6 | 8/8 | 8/8 |
| 1 | C2 | C2 | 8/8 | 8/8 |
| 1 | C2 | C6 | 8/8 | 8/8 |

The four active positions are C2 reading the other bank’s **C2 self-feedback or C6 control signal**, once in each direction. These are controlled port changes with the donor process unchanged, so this establishes an output-sensitive coupling interface on the tested cases. It does not establish a useful solving policy.

The other 33 port changes preserve both full histories and all response/work fields across the eight targets. They are structurally connected but observationally neutral here; we have not demonstrated that they carry useful information. Do not treat this posthoc neutral subset as a prevalidated set of beneficial future mating sites.

An explicitly secondary saved-response check evaluates each diagnostic bank as a fixed bank across all cases: all 74 edge/bank combinations solve zero of the four targets in both poses. No bank is chosen per case. There is no hidden successful combination among these one-port interventions, and no new complete solving claim.

## Reviewed interpretation and recommendation

The insulation result is useful as an engineering control: there is a generic way to retain these entire inherited processes, including stopping and budgets. It costs extra state, approximately the sum of their work, and separate internal outputs. That establishes preservation feasibility, not the missing composition mechanism. It supplies no speed advantage and does not justify placing a twenty-channel composite into the breeding population yet.

The principal scientific correction is to our M28 interpretation. We suspected that an imported C6 expression was operating on the wrong state trajectory. The states do diverge, but on these recorded windows the original C6 expressions produce exactly the same next values on their native and borrowed contexts. We should not keep using that unconfirmed story to justify a larger architecture. The observed C6 value selection and the independently intervened C6→C2 interface are firmer evidence.

The actual missing behavior remains a correct single output across alternatives and orientations. The local selector mixes available parent control values without producing it; direct one-port exchange between preserved processes also fails the four known targets. More capacity may help future evolution, but duplicating two heuristics is not equivalent to constructing a reusable solver mechanic. The conservative 18–20 state width bound only concerns copying these particular programs. Earlier intact positive controls in this representation family already show that useful maze-solving mechanisms are expressible; evolutionary accessibility remains the open question. No known-solver material has entered these lineages.

I recommend a **separately registered causal information-flow study at the C2/C6 interface**, using the existing random-origin genomes and now-used cases. Derive the executed output recurrence and measure which local and propagated signals actually reach its branch decisions. Use controlled changes in distant maze connectivity and the existing paired alternatives to ask whether the interface receives evidence that distinguishes the correct route, or mostly reproduces spatial/orientation heuristics. Preserve all generated layouts and freeze any subsequent modification choices before a fresh holdout. This is a mechanism question, not a proposal to repeat another broad C6 mutation pilot or insert a known wavefront solver.

That study should guide a specific, bounded evolutionary design: change generic regulation or memory only if the measured information bottleneck calls for it, retain useful random-origin histories, and charge all additional work. We have not ruled out sexual evolution or longer runs. We have avoided expanding the substrate on the basis of a causal explanation that this assay did not support.

No M30, new maze campaign, sustained evolution, output-selection policy, enlarged breeding VM or cloud run has been launched. All M29 observations are development evidence from one related set of programs and finite common-time windows. C6 context insensitivity here does not establish universal context insensitivity, nor does the four-edge intervention explain every prior solver failure.
