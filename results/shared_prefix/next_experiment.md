# Proposed V12R: mutation accessibility beyond the emitted wave

Status: proposal only, not launched or preregistered. Q is closed. Its positive-
prefix gate fails0/3 in each origin block. Do not extend it, resume an unchanged
search, alter its source, or tune on Q final cases. Preserve all populations/RNG.

The next uncertainty is whether the current representation/operator produces a
usable local gradient toward branch isolation. Q's saved-data diagnostic finds
few prefix-score improvements; most already improve overall aggregate rank.
That weakens a simple claim that aggregate selection alone suppresses progress.
It does not distinguish a rare but reachable improvement from a very distant
multi-edit mechanism, and says nothing decisive about a higher capacity ceiling.

Freeze an explicitly Q-informed panel before new scientific calls. Include P
route depth9, Q fresh/mixed0 and fresh/current1 (original-founder mutation lineages),
Q fresh/mixed2 (useful immigrant lineage), and the Q95-gene unmutated resampling
wave. These are separate roots/phenotypes, not independent demonstrations of
one shared internal mechanism. Preserve exact ancestors, useful archive variants, and all fresh
random populations; do not substitute a human-written traceback or solver.

A bounded, performance-blind mutation-neighborhood assay should compare short
and longer single-edit walks around each root, plus equal-evaluation fresh random
resampling. Use several independent RNG blocks; freeze edit depth, population
counts, genomes, schedules and cost allowances before scoring. Save every
intermediate genotype/event/RNG, not just good endpoints. Fixture profiling must
allow complete orientation coverage from the outset, avoiding Q's scheduling
amendment. Hard cap about12candidate minutes, local CPU, no automatic extension.

Use genuinely new matched whole layouts with junction versus one-edge-prefix
source positions. Add several asymmetrical arm geometries and bends in the
validation design so success cannot rest only on the equal-arm grammar. Broader
positive-prefix/extra-junction/cycle transfer belongs in a separate untouched
confirmation generated after choices freeze. Exclude all187416 layouts throughQ,
including every software fixture and unqueried pose.

Record normal paired shortest outputs first; also measure output-changing edits,
partial route geometry, unused-arm spill, source/goal reach, survival of old skills,
active channel/read/store changes and actual cost. Treat partial progress as a
candidate gradient, never as a solution. Success-conditioned or static mechanism
analyses must be labeled; do not infer causality from emitted-wave equivalence.

A useful follow-up gate would require repeated independent mutant roots/RNG
blocks producing correct positive-prefix pairs, or a clearly reproducible partial
signal that predicts held-out improvement while retaining the useful primitive.
Exact thresholds and evaluation budgets need preregistration before calls. A
partial-signal result may justify a small controlled selection-policy experiment;
it does not justify a60–90minute run by itself. If mutation supply is mostly
behaviorally inert, a separately controlled variation/operator study is more
informative than merely enlarging the same population or genome ceiling.

Keep random-origin discovery central. The known solver may remain a separate
correctness/runtime control, never a founder, edited repair seed, or ancestor in
these populations. This note neither changes the runtime nor starts an experiment.
