# Proposal after V12R: test useful mutation supply

Status: proposal only. Not launched or preregistered. V12R is complete and closed.
Do not extend its sample, query saved unselected walks on inspected final cases,
resume Q, or treat its final layouts as validation.

R changes the next question. Of 120 candidate memberships per depth, one/four/
sixteen edits change 7/26/75 output sequences, but none improves the registered
discovery partial score. The final-only Qfresh0 descendant improves wave emission
and corridors without solving a new paired branch task. This is evidence to
preserve, but does not pass a two-stage gate. Longer random walks make more changes;
we have not demonstrated a useful direction for selection to accumulate.

## Proposed contrast

Test the existing uniform instruction targeting against execution-informed
targeting while holding the random edit vocabulary, edit count distribution,
genome ceiling, runtime, stopping, input channels, roots and maze schedule fixed.
The hypothesis is that random edits which more often affect expressed computation
will produce useful variation at lower cost. They might instead be more destructive;
retention of existing skills is therefore part of the outcome, not optional.

Before any new selection or mutation experiment, implement an observation-only
instruction activity recorder. Verify native versus observed mask/status/tick/work
parity on independent software fixtures and positive/negative controls. Its records
may include execution counts and read/write dependencies, but no oracle paths,
correctness labels, or hidden human-designed routing modules. Do not use the
observer as a new candidate decoder, stopping rule, or additional inference input.

Freeze a simple targeting rule using these records on a separate new observation
batch. Retain a uniform-target probability so dormant code remains mutable. Specify
how each existing edit kind chooses positions, how zero-activity genomes fall back,
and exactly how the two arms use RNG. Change only targeting, not edit semantics,
fitness, capacity or representation simultaneously. Do not inject a traceback,
goal-gradient follower or known solver into random-origin ancestry.

Use the five exact R roots, independent RNG blocks, unmutated root controls and
fresh random resampling. Keep `accessibility/Qfresh0/1/walk2/d16` as a separately
labeled preserved diagnostic control; it shares Qfresh0 ancestry and does not
count as an additional independent origin. All original Q populations/RNG, R walks
and useful archives remain intact. A new experiment creates new descendants.

The first comparison should again be a bounded mutation-supply assay, with equal
candidate counts and edit-depth coverage, no feedback between successive edits,
and an honest accounting of the observer overhead. Record real work and wall
time in addition to equal evaluation allowances. A local ceiling around 12 candidate
minutes is enough for an initial design; freeze a timing-only schedule before
research calls and stop on a failed cost gate. Avoid changing the cost rule again
after registration: validate it on software fixtures before preregistering.

## Outcomes and confirmation

Use new matched source-at-junction/positive-prefix layouts, asymmetric arms, bends,
paired goals, pruned corridors and disconnected controls. Broader validation must
include longer arm forms from the outset; R's final-only gain exposed that limitation
of its validation support. Final data remain independently seeded and generated
only after every choice is committed and pushed. All poses must be covered.

Measure genotype changes, actual expression changes, output changes, spill/missing
cells, old-skill retention, normal complete shortest pairs and cost. Keep partial
signals separate from solving. Static liveness approximations and observed activity
are not causal proof that an instruction controls the route.

Before running, preregister numeric criteria requiring improvement over both
uniform targeting and fresh resampling across multiple roots/RNG blocks, with
retention of old skills and confirmation on new layouts. A partial-only advantage
can justify a small selection experiment, not a 60–90 minute run. A lack of useful
variation in both arms should trigger a separate representation/regulation study,
not indefinite scaling of the same operator. R did not test a larger capacity
ceiling, and does not close that hypothesis or the random-origin research track.

Exclude all **191,784 whole layouts through R**. Its helper returns through Q only;
append R fixtures, software fixtures, discovery, validation and confirmation
`mazes.json.gz` files. Do not infer independent evidence from poses or repeated
route forms. No part of this proposal authorizes a known-solver lineage or automatic
budget extension.
