## Step2: what the architecture permits and makes fragile

The native kernel already has8 persistent spatial channels and64 site-local
registers. Registers reset each site/tick; channels are double-buffered. Source,
goal flags and a goal pulse are supplied. Channel2 emits the output andchannel7
can request stopping at the source, subject to endpoint checks. Quiescence also
stops execution. Program dispatch and spatial work are capped.

Therefore extra raw storage is not the only question. A successful extension may
need to retain a useful propagated state, create a new selective computation,
write an appropriate output, and coordinate stopping. Those operations share
registers and channels. Existing controls show representability and some repair
searchability; they do not establish an easy route to composing abilities.

Uniform mutation changes arbitrary instructions or operands. It can break
dependencies, gates or stop conditions. R shows output changes becoming more
frequent with depth,mostly destructive. This is not proof that every neutral
instruction is useless, or that a larger regulatory representation cannot help.

Recombination is a reasonable additional source of coordinated changes. It does
not guarantee ability transfer: donor register36 orchannel3 may have a different
meaning in another lineage. Our scratch registers lack inherited semantic labels.
Arbitrary concatenation/truncation also risks multiple writers and accidental
early stopping. Do not describe a child as combining skills merely because it
contains instructions from two successful parents.

The static audit checks240 directed pairings among16 panel identities. Only8
pairings admit the deliberately conservative candidate splice rule: exact
matching runs of at least2instructions bound differing1–16instruction segments,
scratch-write sets andpersistent-store sets agree, and donor live-in scratch
requirements add none to those of the replaced segment. The256gene limit must
hold without truncation. Six eligible directions are within the old shared-
ancestor/Branch family;two are betweenQfresh0anditsRdescendant. No unrelated
cross-family combination qualifies. These are structural matches, not certified
historical homology or functional compatibility. `architecture.json` records
everycomparison and verifiesall2913prior completion entries.

## Step3 decision: bounded complementary recombination versus mutation

Choose one change to the reproduction process: allow a bounded structurally
aligned splice from a compatible donor chosen for complementary current-batch
fitness. Retain the same ordinary single-edit mutation afterwards. Compare with
the identical mutation-only policy and matched fresh resampling. No runtime,
state representation, output decoder or stopping change in this experiment.

This is a test of the combined mating-and-splicing policy; it cannot isolate
donor selection from splice mechanics. It deliberately tests within-compatible-
lineage composition first. Cross-family semantic module transplantation is
premature and remains a separate possible future representation study.

Select the first parent by the common existing lexicase rule. Search a bounded
donor shortlist for structural eligibility, favoring performance on cases where
the first parent is weaker. Use complete pairs/normal correctness before partial
credit. Exclude identical genotypes andself-mating; log absent-compatible-donor
fallbacks. Structural compatibility cannot use holdout scores or oracle paths.
Log two-parent ancestry, exact segments, mutations and RNG. Measure actual splice
frequency and behavioral/skill gains so an inert operator is not misread as a
negative test of arbitrary sexual recombination.

Use carried andfresh origins,threeindependentreplicates,commoninitialpools within
eachreplicate,protectedanchors andsamearchives/evaluationcounts. A fixed75minute
search-wall budget will test sustained accumulation without an early-success
requirement. Preflight is forcorrectness,cost andoperator activation only. All
choices freeze before another untouched final set. Full parameters, budget,
sampling andverification belong in the new V12S preregistration before any
scientific evaluation. This note itself does not launch the search.

## External grounding and limits

- Stanley andMiikkulainen,2002, [NEAT](https://direct.mit.edu/evco/article/10/2/99/1123/Evolving-Neural-Networks-through-Augmenting): matching differing structures andprotectinginnovations are explicitparts ofan evolved-network method. This doesnotproveour register-program crossoverwillwork.
- Brameier andBanzhaf,2002, [linear-GP variation anddiversity](https://www.cs.mun.ca/~banzhaf/papers/eurogp02_dist.pdf): distinguishes changes toeffectivecode fromrawinstruction changes andcomparesmutation/crossover. Our staticinterfaces are anapproximation; effectivebehaviorwillstillneedmeasurement.
- Earle etal., [Pathfinding Neural Cellular Automata](https://arxiv.org/html/2301.06820v1): localarchitecturescan supportpropagationandpath extraction;theirlearningmethod isnotour random-origin evolutionary process.

Random-origin discovery remains the objective. Known solver controls stay separate;
no manually authored routing/traceback module enters the populations. General
solving, beneficial multirange computation and competitive speed remain unproven.
