# Proposal after V13B: measure access to selective emission

Proposal only, not registered or launched. Do not extend B, resume its populations
silently, nominate from inspected final outcomes, or reuse final mazes for training.
Exclude all 279,824 whole layouts through B plus subsequent fixtures. Preserve the
random-origin track, all old populations/RNG, rare specialists and diversity.

B's new shaping score distinguishes excess-cell counts but does not improve
primary branch solving in 30 matched generations. Only one post-founder nomination
screen fits. All fresh selective primaries still emit the route with extras on
every prefix-one/two final input. The one corridor advantage comes from a new unmutated
random immigrant. A constructed known-solver STORE repair is accessible, but that
does not establish a useful mutation gradient from an actual random-origin
spreader. Neither a stronger objective claim nor a longer-run gate is supported.

The next bounded question should be: **can small mutations of the preserved
random-origin genomes reduce incorrect output while retaining genuine route
coverage and paired successes across independent contexts?**

Before any new organism calls, freeze an explicitly B-informed parent panel and
an equal per-parent mutation schedule. Include a B overgrowth selection, a prior
Z source-at-junction specialist, the carried one-extra-cell specialist and suitable
unchanged/random-resampling controls. Do not claim this panel was chosen blind to
B. Choose exact panel size and candidate allowance by timing-only preflight and
register them before assay generation; roughly 12 candidate minutes is a planning
ceiling, not permission to run now. Keep runtime, capacity and normal emission
fixed. All changes must use the existing random mutation operator; do not write
solver instructions, target hand-selected loci, transplant a known solver, clean
outputs, or reward genome length.

Sample a fixed, reproducible one-edit neighborhood from each parent and preserve
all events, including neutral changes and regressions. On new matched contexts,
measure correct complete goal pairs, retention of the parent's actual successes,
full-route coverage, excess cells, and behavioral neutrality separately. Compare
the two existing fitness rankings on the SAME candidate set with the same oracle
evaluation allowance. This isolates candidate accessibility and ranking from
population drift; it is not itself an evolution-policy comparison.

Preregister the analysis of heritable improvements, neutral steps and loss of
coverage. If a bounded second-edit phase is included, its allowance and parent
selection rules must be fixed before the first screen: compare best-first and
neutral stepping candidates under equal budgets, with uniform controls, rather
than improvising after looking at successes. All selected candidates must be
frozen/pushed before an untouched confirmation set; final outcomes never reselect.
Keep synthetic known controls separate and label their easier starting point.

The desired signal is normal, two-goal upstream improvement across independent
contexts while retaining previous successes—not merely smaller floods, attractive
fitness, one lucky pose or a later forced-trace frame. Fix numerical continuation
gates after timing-only preflight and before scientific screening. If mutations
mostly erase the path or leave behavior unchanged, quantify that bottleneck;
consider neutral drift or representation/operator changes in a later separate
controlled study. If useful improvements are accessible but existing ranking
misses them, test selection/nomination rather than assuming more capacity helps.
No unchanged 75-minute run is automatically justified by either outcome.

Sexual recombination remains a separate research option. B does not test it or
satisfy the actual-transfer gate: >=10% of scheduled matings must retain at least
two changed donor instructions after mutation across >=8 generations, in 2/3
replicates for each sexual policy in both origins, before the prepared long
comparison. Do not combine that intervention with this proposed accessibility
assay or activate the existing sexual specification.
